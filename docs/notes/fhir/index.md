# FHIR

*Study notes for the HL7 FHIR Implementer: Foundational exam - the FHIR standard from
resource fundamentals through data types, exchange paradigms, implementation guides,
and security and privacy.*

**FHIR** (Fast Healthcare Interoperability Resources) is HL7's standard for exchanging
healthcare information electronically. It combines the best of earlier HL7 standards
(v2, v3, CDA) with modern web technologies - REST, JSON, OAuth 2.0 - to make healthcare
interoperability more accessible and implementable.
